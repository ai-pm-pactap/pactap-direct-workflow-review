# Pactap Direct workflow review

This repository contains a static viewer and encrypted review content. A shared passphrase is required to read the workflows. The passphrase and plaintext sources are kept outside this repository.

Use the HTTPS GitHub Pages site. Unlocking takes place in your browser; the app does not save the passphrase or decrypted content in browser storage. Refresh or use Lock to close the workspace. Exports and printed copies are plaintext.

Shared access has no individual revocation or access audit. Passphrase rotation cannot revoke earlier downloaded ciphertext or exports. Trust the repository publishers and the GitHub Pages origin. Do not submit passwords, sensitive content or security findings in public issues; report concerns privately to the Pactap project owner through your established contact.
